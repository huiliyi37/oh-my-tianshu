# Agent Note：TUI 常驻待办面板

Status: implemented

[English](2026-08-23-tui-todos-panel.md) | 中文

## 问题

`todo_write` 记录模型的计划，数据也已经通过 [`todos` 投影键](../../../../packages/todo/tool-todo/README.md)从会话日志投影出来。用户缺的是随时可见的一瞥：此前列表只在按需打开时出现——`/status` 面板的任务段与 `/tasks` 窗格都渲染它，但都要用户主动打开。Claude Code 给它的 TodoWrite 工具配了一个工作期间常驻可见的待办面板。此处的真实增量是一张紧凑的常驻卡片加 `/todos` 开关，而不是首次提供待办视图。

## 决策

在 [`packages/tui/tui`](../../../../packages/tui/tui/README.md) 内做纯 TUI 改动：把 `todos` 会话投影渲染为紧凑常驻卡片，并注册 `/todos` 命令切换显隐。无 harness 改动、无新包、无新事件词汇表。TUI 已经订阅该投影并缓存其值（`app.ts` `taskItems`），所以这张卡片增加的是渲染器与开关，而不是数据管线。

### 数据源与回合边界

该投影的 fold 语义是：`todo/write` 全值替换列表；`turn/start` 把 fold 重置为 `null`；`turn/end` 保留已完成的清单可见。因此面板不把 `null` 当作"隐藏"：控制器维护一个保留快照（`todosRetained`），只吸收非空的投影值，可见清单跨回合黏滞，不随每个 `turn/start` 闪烁消失。`null` 只在会话首次写入前渲染（空闲占位行）；显式空写入渲染全部完成行。两种空语义保持可区分，不同于 `/status` 刻意把 null 当占位符的合并。

### 渲染面

纯渲染模块 `src/format/todos-panel.ts` 遵循渲染意图约定：`projectTodosPanel(todos, opts)` 参数进、行文本出，无模型交互。收起态是单行卡片——标题、三态计数（`✓`/`⏳`/`□`）、当前进行中项；`all` 展开限行的明细列表（缺省含摘要共六行，超出折叠为 `└ …(+N)` 尾行）。面板渲染于 glance 条与任务窗格之间，显隐门控在 `renderTodosPanel` 内。

### 表面分工

`/status` 保留其按需的完整面板，以及任务段刻意把 `null` 当占位符的合并语义；`/tasks` 继续负责后台任务执行。新卡片是唯一区分 `null`（从未写入）与空列表（全部完成）的表面，并独占常驻、可切换的呈现。其他表面不变。

### 命令面

`/todos`（无参）切换显隐；`/todos all` 展开/收起明细并显示面板；其他参数回显用法。命令注册进 TUI 内置斜杠注册表（`BUILTIN_COMMAND_NAMES`），因此出现在 `/help` 与命令面板中。keymap 面板只列键盘快捷键，因此没有 `KEYMAP_ENTRIES` 条目。显隐与展开是逐会话的 UI 状态，`/clear` 与会话切换会复位。

## 备选方案

### 为什么不扩展 `/status`？

状态面板是按需打开、全宽的；常驻卡片必须小巧、始终可见、一眼可扫。合并两种需求要么撑大状态面板，要么把卡片藏进一个必须主动打开的面板后面。

### 为什么不做 harness 级待办面板服务？

投影已经存在，卡片只是展示；服务会重复日志已经提供的折叠，并为单个适配器加宽 harness。

### 为什么不并入 `/tasks`？

`/tasks` 负责后台任务执行；待办是模型的计划状态。合并两个领域会搞乱两个面。

### 为什么不开新包？

改动只触及 TUI 渲染及其测试；新包不携带独立能力，会违反当前所有者要求。

## 后果

- 面板行为经真实渲染管线钉住：格式模块单测（空闲、全部完成、摘要、超限截断）、live-panels 对新快照字段的契约测试、以及 `app.spec` 对黏滞语义、`/clear` 复位与用法回显的集成测试。PTY keyless 快照是刻意的延后；需要时复用 `examples/tui/tests` 下 fox-welcome 的快照驱动器即可。
- 回合边界重置后，保留列表可能属于上一回合；黏滞是对「fold 在回合开始清空」的诚实呈现，显式空写入仍清为全部完成态。
- `null` 与空列表是只有本表面保留的语义；共用渲染器会重新引入 `/status` 的合并，所以卡片保持自己的渲染路径。
- 切换是逐会话的 UI 状态，不持久化；重开的会话从隐藏开始。
- 卡片与活动带共享高度预算；限高与收起状态约束成本，长列表显示计数加当前项而非全部行。
